# 🎮 How to Open & Play Ball Breaker Game

## 🚀 Quick Start (3 Easy Steps)

### Step 1: Go to Your Repository
Open your browser and go to:
```
https://github.com/Harshini728/ball-game
```

### Step 2: Click on `index.html`
- Look for the file named **`index.html`** in the file list
- Click on it to open it

### Step 3: Click "Raw" or the Download Button
- At the top right of the file preview, you'll see buttons
- Click the **`Raw`** button (or the download icon)
- This will open the game in a new tab

---

## 📱 Method 1: Using GitHub Pages (Recommended)

GitHub Pages allows you to host your game online for free!

1. Go to your repository settings
2. Scroll down to **Pages** section
3. Under "Source", select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**
5. Wait 1-2 minutes for deployment
6. Your game will be at: `https://Harshini728.github.io/ball-game/`

---

## 💻 Method 2: Run Locally on Your Computer

### Windows:
1. Download the files from GitHub (green "Code" button → "Download ZIP")
2. Extract the ZIP file
3. Double-click **`index.html`** to open in your browser

### Mac:
1. Download the files from GitHub
2. Extract the ZIP file
3. Double-click **`index.html`**
   - Or right-click → "Open With" → Your browser

### Linux:
1. Download/clone the repository
2. Open terminal in the folder
3. Run: `python -m http.server 8000`
4. Open browser and go to: `http://localhost:8000`

---

## 🌐 Method 3: Using an Online Editor

### Using CodePen:
1. Go to https://codepen.io
2. Create a new pen
3. Copy-paste the code:
   - **HTML** → Copy all of `index.html`
   - **CSS** → Copy all of `style.css`
   - **JavaScript** → Copy all of `script.js`
4. Click **Save** and play!

### Using Replit:
1. Go to https://replit.com
2. Click **Create** → New Repl
3. Select **HTML/CSS/JS**
4. Create these files with the code from your GitHub repo
5. Click **Run** to play!

## 🎮 How to Play (Once Opened)

1. **Click "Start Game"** button to begin
2. **Move your mouse left/right** to control the paddle
3. **Bounce the ball** with your paddle to hit bricks
4. **Break all bricks** to complete the level
5. **Press SPACE** to pause/resume at any time
6. **Survive with your 3 lives** and get the highest score!

---

## 🔧 Troubleshooting

### Game doesn't open?
- Make sure you're opening `index.html` (not `style.css` or `script.js`)
- Try a different browser (Chrome, Firefox, Safari, Edge)
- Try Method 2 (Run Locally) instead

### Game is slow?
- Close other browser tabs
- Make sure you're using a modern browser
- Try full-screen mode (F11)

### Can't move paddle?
- Make sure your mouse is over the game canvas
- Try clicking on the canvas area first
